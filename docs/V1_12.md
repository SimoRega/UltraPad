# UltraPad 1.12

## Funzioni

| Priorità dell'analisi | Implementazione |
|---|---|
| Explorer ridimensionabile | Drag o frecce sul divisore, preferenza per utente; cartelle collassabili |
| Menu contestuale unico | Explorer, tab e click destro sulla home; tastiera Shift F10, frecce e Escape |
| Breadcrumb | Workspace, progetto e cartelle reali; apertura e selezione della cartella |
| Split editor | Due file dello stesso progetto, due provider; pannelli verticali su schermi stretti |
| Command palette | Ctrl/⌘ Shift P, azioni filtrate per contesto e permessi |
| Ripristino tab | Sessione per account/progetto, ordine e secondo file; pulsante Riprendi sessione |
| Documenti completi | Menu Inserisci: link, immagini raster incorporate, tabelle e indice |
| Import multiplo/drop | Testo/formato UltraPad con conferma del contenuto per ogni file; errori nominativi |
| Grafica/toolbar | CSS dedicato ai componenti della shell, spaziature/focus, controlli uniformi e larghezze indipendenti |
| Recupero affidabile | Test di checkpoint/restore con immagini, schema negoziato, protezione errori storage e presenza bounded |

Gli editor lavagna, planner, travel planner, fogli, codice e strumenti isolati conservano le capacità della 1.11 e partecipano alla navigazione/editor affiancati. Immagini e tabelle nei TXT richiedono la vista visuale; download TXT contiene il testo, download UltraPad conserva tutto. Office si importa singolarmente per rivedere la conversione. Ospite resta solo nella scheda, senza salvataggio sul DB.

## Aggiornamento

Versioni web/desktop 1.12.0 e cache shell v1.12. Nessuna migrazione SQL nuova. Distribuire prima Worker, poi web/desktop aggiornati. L'endpoint initialize e la validazione estesa non esistono nel backend 1.11. Il merge non costituisce prova di deploy, né certificazione OAuth/backup/runner nell'ambiente produttivo.

## Verifica riproducibile

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm test:integration
pnpm test:setup
pnpm test:desktop
node --test services/runner/runner.test.mjs
pnpm build
pnpm exec playwright install --with-deps chromium
pnpm test:e2e --workers=2
```

Per altre piattaforme: installare Firefox/WebKit e usare `--browser=firefox` oppure `--browser=webkit` sulla suite `tests/e2e/v112.spec.ts`. Ogni suite deve usare una directory SQLite distinta (variabile `ULTRAPAD_TEST_STATE`) se eseguita simultaneamente. Le nuove job CI hanno runner isolati. I gate operativi ancora aperti sono indicati in ADR 0015 e PROGRESS; non richiedono di introdurre persistenza o autorizzazioni fittizie.
