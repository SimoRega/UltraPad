# UltraPad 1.8 — icone e spazio di scrittura

Richiesta del proprietario: riprodurre le modifiche approvate per navigazione,
tab simili a Chrome e strumenti dell'editor più compatti.

- FileIcon SVG condivisa fra albero, ricerca per nome, home, recenti, ospite e tab.
  Cartelle, TXT/RTF/DOC, Markdown, HTML/XML, Java (tazzina), JSON/YAML,
  linguaggi, LaTeX, planner e fogli hanno simboli coerenti. Formati sconosciuti
  usano il foglio di testo. Icone decorative: i nomi restano accessibili.
- Tab arrotondate con raccordi inferiori, stato attivo, nome troncato, tooltip
  e X separata. Si preserva la chiusura sicura dei file server e delle copie locali.
- Vista documento/sorgente, commenti e Focus su una barra. Collegamenti e
  larghezza nel menu Opzioni editor. Il nome workspace e Modifica sono allineati.
- Barra rich text: font, punti, B/I/U, undo/redo ed export. Formattazione apre
  Testo/Paragrafo/Stili in un pannello sovrapposto, senza togliere spazio al testo.
  Strumenti sorgente raccoglie inserimenti, formatter, validazione e indentazione.
- I menu si chiudono con click esterno o Escape; Escape torna al pulsante.
  Le selezioni Quill restano memorizzate per applicare formati dal pannello.
- Release web e desktop 1.8.0; cache shell aggiornata. Nessuna dipendenza nuova.

Solo presentazione: nessuna migrazione SQL o modifica di protocollo, ACL,
contenuti CRDT, origini o sandbox Electron. Le icone non aggiungono supporto
all'importazione di un formato. Il desktop usa lo stesso frontend aggiornato
al prossimo packaging. Deploy remoto e installer non sono eseguiti da questo aggiornamento.
