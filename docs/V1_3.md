# UltraPad v1.3

- X nelle tab: chiude il file, seleziona un'altra tab se disponibile o torna
  al progetto. Le modifiche offline persistite saranno inviate alla riapertura.
- Workspace **Temporanei** nella barra laterale, accessibile anche da /temporary.
  Chiudere l'editor conserva l'appunto; eliminarlo richiede conferma.
- Pulsante Espandi/Riduci nella barra workspace: mostra i nomi completi.
- Anteprima nelle card home/workspace, con testo server e pulsante Apri
  nell'editor. Il testo è limitato visivamente a 12.000 caratteri.
- Account: nome e cognome suggeriti dalla mail, modificabili e salvati in Auth;
  upload/rimozione foto PNG/JPEG/WebP fino a 5 MiB, ridimensionata a 64×64 (fino a 32×32 per immagini complesse).
- Avatar e iniziali delle persone con il file aperto nei progetti di team,
  nella home e sopra l'editor. Tooltip con nome; presenza ogni 10 secondi,
  include lettori e autore, deduplicata per account. File personali esclusi.

## Aggiornamento

Aggiornare il branch della release, installare con pnpm install --frozen-lockfile,
riavviare pnpm dev per l'ambiente locale. In hosting aggiornare Worker e frontend
insieme, mantenendo le variabili configurate e gli header CSP distribuiti.
Non ci sono nuove migrazioni: restano richieste le 001–004 della v1.1.
La cache shell cambia a v1.3; ricaricare i vecchi client.

I temporanei conservano la durata della scheda. Il profilo è sincronizzato
nell'account Supabase, senza nuovo bucket. La presenza non indica che ogni
modifica sia già salvata: vale sempre l'indicatore dell'editor. Nome/cognome
suggeriti dalla mail possono richiedere correzione manuale. Anteprima testuale
anche per TXT formattati; aprire l'editor per vedere la formattazione.

Test locali usano Auth/ACL fixture per browser e room; non certificano il
salvataggio del profilo su Supabase remoto o un deploy cloud. Dettagli delle
scelte: ADR 0005. Gate R1 della documentazione PROGRESS invariati.

## Evolutive 1.3.1 — issue #1

- Intestazione home/workspace compatta, tre azioni disposte orizzontalmente.
- Disposizione file: Griglia, Elenco, Raggruppati. Le card raggruppate usano
  tema, tipo file, workspace o giorno di modifica; ricerca e anteprime restano
  disponibili. La disposizione scelta viene ricordata per utente/browser.
- File temporaneo apre subito un TXT senza dialogo. «Nome e formato» cambia
  successivamente titolo/estensione conservando il contenuto. File singolo
  continua a chiedere il nome e salva nel database.
- HTML, MD e TEX offrono «Anteprima affiancata», aggiornata dal contenuto
  corrente (anche offline o ricevuto da collaboratori). «Apri in un’altra
  pagina» apre una copia dell’anteprima corrente, isolata e senza opener.
- Script HTML, risorse esterne e moduli sono disattivati. LaTeX è una
  traduzione HTML con formule, non una compilazione PDF: pacchetti/comandi
  non supportati vengono segnalati. Massimo 50.000 caratteri per preview.

Nessuna migrazione SQL necessaria oltre alle migrazioni della v1.3.
Ricostruire e distribuire il frontend per attivare le evolutive e la CSP.
